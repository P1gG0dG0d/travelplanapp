# 给 AI 的行程规划提示词

> 使用方法：在 App「更多 → 生成 AI 提示词」一键生成并复制（会自动填入你的个人画像和旅行信息），
> 粘贴到任意 AI 助手（如 ChatGPT、Kimi、豆包、DeepSeek 等）即可让它按统一格式输出行程。
> 下面模板中 `{...}` 是占位符，你照着填即可。

---

你是专业的旅行规划助手。请为下面这次旅行规划详细行程，并**严格按指定的 Markdown 格式输出**，不要输出格式之外的任何解释或寒暄。

## 【我的个人偏好】
- 口味：辣度 {不吃辣 / 微辣 / 中辣 / 重辣}；忌口/过敏 {填，无则写“无”}；偏爱菜系 {如 川菜 / 粤菜 / 本地小吃}；每餐人均预算 {如 30–80 元}
- 酒店：每晚预算 {如 300–500 元}；档位 {经济型 / 中端 / 高端}；位置偏好 {近地铁 / 近火车站 / 近景区 / 市中心 / 安静}；早餐 {需要 / 不需要}
- 出行：市内交通 {地铁优先 / 打车 / 公交 / 步行}；体力 {能走 / 一般 / 需少走多休息}；同行 {独自 / 带老人 / 带小孩}

## 【旅行信息】
- 城市：{如 成都、重庆}
- 日期：{开始日期，如 2026-05-01}，共 {N} 天
- 节奏：悠闲（每天 2–3 个景点，不赶行程）

## 【规划要求】
1. 按天分成「上午 / 午餐 / 下午 / 晚上」，每天安排 2–3 个景点，悠闲不赶。
2. 同一天的景点按地理位置就近安排，尽量减少往返折返；涉及跨城市时，在换城市当天安排好交通衔接。
3. 每个景点给出：地址、建议游玩时长（小时）、是否需要提前预约（中国热门博物馆/景点常需预约）。
4. 午餐、晚餐推荐符合我口味的饭店，并标注大致人均价格。
5. 每天推荐符合我预算、档位与位置偏好的酒店，标注入住/退房日期。
6. 火车/高铁等车票信息单独列出（车次、出发站→到达站、出发时间、座位）。

## 【输出格式】严格使用下面的 Markdown 模板

```
---
旅行名称: {城市} {N}日游
开始日期: {开始日期}
---

# 第1天 · {城市}
## 酒店
- 名称: 全季酒店(春熙路店) | 地址: 成都市锦江区xxx | 入住: 05-01 | 退房: 05-02

## 上午
- 景点: 宽窄巷子 | 地址: 成都市青羊区xxx | 时长: 2小时 | 预约: 否

## 午餐
- 饭店: 陈麻婆豆腐 | 地址: 成都市xxx | 人均: 60元

## 下午
- 景点: 武侯祠 | 地址: 成都市武侯区xxx | 时长: 3小时 | 预约: 是 | 预约日期: 05-01

## 晚上
- 景点: 锦里 | 地址: 成都市武侯区xxx

# 车票
- 车次: G1234 | 成都东→重庆北 | 2026-05-03 14:00 | 二等座
```

现在，请开始规划。
