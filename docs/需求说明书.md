# 「好奇旅行」需求说明书（v1）

## 定位
- 名称：好奇旅行 ｜ 包名：`com.haoqi.travel`
- 平台：Android（原生 Kotlin + Jetpack Compose + Material 3）
- 模式：单机自用（无账号、无云端，数据存手机本地）
- 地区：中国大陆（高德地图）｜ 界面：中文

## 功能清单
1. **旅行管理**：新建/编辑一次旅行（多城市、多天）
2. **地图主页**（默认首屏）：高德地图 + 酒店/景点/饭店 + 我的位置 + 当日行程高亮
3. **地点录入**：MD 导入自动定位（高德地理编码）+ 手动搜索/长按选点，查不到或重名时手动确认
4. **酒店**：记录在地图上（含入住/退房日期）
5. **车票**：独立页 + 出发提醒（火车/高铁默认提前 45 分钟，可自定义）
6. **门票/预约**：记录哪些景点要预约、预约日期、是否已买票 + 提醒
7. **自动排程**：本地规则引擎、悠闲档（一天 2–3 点）、上午/下午/晚上三段、可手动拖动；饭店自动排进午餐/晚餐
8. **MD 导入/导出** + 本地自动备份
9. **一键跳高德导航**
10. **行程总览统计卡**（天数/城市数/景点数/预计花费）
11. **个人画像**（口味/酒店预算/出行偏好）+ **一键生成 AI 提示词**

## v2 暂不做
AI 大模型排程、云端同步/多人共享、花费记账、目的地天气、心愿单、旅行笔记照片、行李清单。

## 技术选型
| 项 | 选型 |
|---|---|
| 语言/UI | Kotlin + Jetpack Compose + Material 3 |
| 地图 | 高德地图 Android SDK（3D） |
| 地理编码 | 高德「地理编码」API |
| 数据库 | Room（SQLite） |
| 提醒 | AlarmManager 精确闹钟 + WorkManager |
| MD 解析 | 自写解析器（YAML 头 + 标题层级） |
| 构建 | Gradle 8.7 + AGP 8.5.2 + Kotlin 2.0.21 |
| 兼容 | minSdk 26（Android 8.0）+，compileSdk 34 |

## 数据模型（草案）
- **Trip** 旅行：名称、开始日期、天数、城市列表
- **Place** 地点：名称、地址、经纬度、类型（景点/饭店/酒店）、城市、建议时长、开放时间、预约要求/状态
- **HotelStay** 酒店入住：地点 + 入住/退房日期
- **Ticket** 车票：类型、车次、出发/到达站、出发/到达时间、座位、提醒提前量
- **Reservation** 门票/预约：景点、预约日期、状态
- **DayPlan** 日程：第几天 + 时段（上午/下午/晚上）+ 有序地点列表
- **Profile** 个人画像：口味、忌口、菜系、每餐预算、酒店预算/档位/位置/早餐、市内交通、体力、同行
