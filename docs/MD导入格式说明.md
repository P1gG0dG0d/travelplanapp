# 「好奇旅行」MD 导入格式说明

导入的行程文件是一个 `.md` 文件，结构为「**YAML 头部 + Markdown 正文**」。

## 1. YAML 头部（可选，但建议写）

```yaml
---
旅行名称: 成都-重庆 5日游
开始日期: 2026-05-01
---
```

- `旅行名称`：本次旅行名字。
- `开始日期`：第一天日期，格式 `YYYY-MM-DD`，用于推算后面各天是几号。

## 2. 正文结构

- 一级标题 `# 第N天 · 城市` 表示一天。
- 二级标题 `## 上午 / 午餐 / 下午 / 晚上 / 酒店` 表示一天中的时段。
- 每个地点用一行 `- 类型: 名称 | 字段1 | 字段2 | ...` 表示，字段用 `|` 分隔。

### 支持的地点类型

| 类型 | 出现在 | 关键字段 |
|---|---|---|
| 酒店 | `## 酒店` | 名称、地址、入住、退房 |
| 景点 | 上午/下午/晚上 | 名称、地址、时长、预约、预约日期 |
| 饭店 | 午餐/晚上 | 名称、地址、人均 |

### 字段说明（都是可选的，缺了 App 会提示你补或自动补）

| 字段 | 说明 | 示例 |
|---|---|---|
| 名称 | 地点名，必填 | 宽窄巷子 |
| 地址 | 用于地图定位，缺了会用名称自动查坐标 | 成都市青羊区xxx |
| 时长 | 建议游玩时长 | 2小时 |
| 预约 | 是否需要提前预约：是/否 | 是 |
| 预约日期 | 预约的日期 | 05-01 |
| 人均 | 饭店人均价格 | 60元 |
| 入住 / 退房 | 酒店日期 | 05-01 / 05-03 |

### 车票

车票单独放，格式：

```
# 车票
- 车次: G1234 | 成都东→重庆北 | 2026-05-03 14:00 | 二等座
```

字段依次为：`车次`、`出发站→到达站`、`出发时间`、`座位`。

## 3. 完整示例

```markdown
---
旅行名称: 成都-重庆 5日游
开始日期: 2026-05-01
---

# 第1天 · 成都
## 酒店
- 名称: 全季酒店(春熙路店) | 地址: 成都市锦江区xxx | 入住: 05-01 | 退房: 05-03

## 上午
- 景点: 宽窄巷子 | 地址: 成都市青羊区xxx | 时长: 2小时 | 预约: 否

## 午餐
- 饭店: 陈麻婆豆腐 | 地址: 成都市xxx | 人均: 60元

## 下午
- 景点: 武侯祠 | 地址: 成都市武侯区xxx | 时长: 3小时 | 预约: 是 | 预约日期: 05-01

## 晚上
- 景点: 锦里 | 地址: 成都市武侯区xxx

# 车票
- 车次: G1234 | 成都东→重庆北 | 2026-05-03 14:00 | 二等座
```

## 4. 容错规则

- 缺地址 → 用高德「地理编码」按名称自动查坐标。
- 查不到 / 重名 → 弹出让你在地图上搜索确认。
- 缺时长 / 预约 → 导入后提示你补。
- 多余的空行、顺序打乱都不影响解析。
