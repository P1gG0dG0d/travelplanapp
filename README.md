# 好奇旅行 · HaoQiTravel

单机版 AI 旅行规划 App：填好时间与城市，AI 自动生成完整行程（景点 / 酒店 / 饭店 / 城际交通），一键导入后可在高德地图上查看与导航、按出发时间自动提醒。

## 技术栈

- Kotlin + Jetpack Compose (Material 3)
- 高德地图（3D 地图 + 地理编码）
- Room（本地数据库，纯离线，数据只存本机）
- 豆包 · 火山方舟 API（AI 行程生成：联网返回**真实**车次/航班/酒店，再照抄进行程，杜绝编造车次）

## 功能

- **AI 规划**：填出发地 + 每天城市 + 特殊要求，AI 结合口味/预算/节奏/出行档次偏好生成行程，可反复对话修改到满意；
- **联网搜索**：两步法——先联网核实真实车票/酒店清单，再让规划模型只从清单里照抄；查不到就写「建议/待定」，绝不编造；
- **行程页**：按天 + 时段（上午/午餐/下午/晚餐/晚上）排布，可拖动调整、手动加地点；
- **车票**：录入真实车票后按发车时间提前提醒（高铁/火车 45 分钟、航班 2 小时、大巴 30 分钟）；
- **地图**：地点落点、点标记导航；
- **预约提醒**：需预约/购票的景点自动标记，到预约日提醒。

## 安装

到 [Releases](../../releases) 下载最新 `app-release.apk`，直接安装（需允许"安装未知来源应用"）。

## 自己构建

1. 申请 [高德开放平台](https://lbs.amap.com/) Key（Android 平台，填应用包名 `com.haoqi.travel` 和你本机的调试 SHA1）；
2. 在项目根目录 `local.properties` 里加一行（该文件不进 git）：
   ```
   amap.key=你的高德Key
   ```
3. 申请 [火山方舟](https://console.volcengine.com/ark) 的 API Key（App 里默认用豆包，Key 只存在本机）：
   - 在方舟控制台创建 API Key；在「开通管理」里启用 **联网内容插件**（否则联网搜索不可用）。
   - 模型名称填方舟的模型 ID（如 `doubao-seed-2-0-lite-260428`）；若提示模型不存在/未开通，就在方舟控制台开通该模型，或创建一个「推理接入点」，把 `ep-xxxxx` 填进 App；
4. 装好后在 App「更多 → AI 生成设置」里选服务商、填 Key 保存；
5. `./gradlew :app:assembleRelease` 构建。

## 📘 申请豆包 API 完整流程（火山方舟接入说明书）

> 本节同时适用于：App 首次使用前的「申请 API Key + 开通模型 + 创建推理接入点」，以及任何接入报错的排查。以下步骤按 2026 年方舟控制台编写，若菜单位置有变，可用控制台右上角搜索直达功能页。

### 一、注册并开通方舟服务（10 分钟）

1. **注册火山引擎账号**：访问 <https://www.volcengine.com> 注册（手机号即可），完成**实名认证**（个人实名即可，控制台「账号中心 → 实名认证」）。
2. **进入火山方舟**：打开 <https://console.volcengine.com/ark>，确认右上角区域是 **「华北2（北京）」**（豆包模型默认在此区域）。
3. 首次进入按页面引导**开通方舟服务**（同意服务协议，一般即时生效，免费开通、按量后付费）。

### 二、创建 API Key（第 1 个 Key）

1. 方舟控制台左侧菜单 → **「API Key 管理」**。
2. 点 **「创建 API Key」**，复制生成的 Key（形如一串较长的字符）。
3. **保存好 Key**：关闭页面后不再显示完整值，只能重新创建。Key 只填进本机 App，不要贴到网上或提交到代码仓库。

### 三、开通模型服务（关键！不做这步会报 ModelNotOpen）

1. 左侧菜单 → **「开通管理」**（有的版本叫「模型广场/开通管理」）。
2. 在 **「模型服务」** 列表里搜索 **`doubao-seed-2-0-lite`**（本 App 默认模型，全名 `doubao-seed-2-0-lite-260428`），点 **「开通」/「立即开通」**，按提示确认。
   - 开通是免费的，只代表「允许你的账号调用」，实际费用按调用量后付。
3. **没搜到？** 换一个能搜到的豆包 2.x 模型开通（如 `doubao-seed-2-0-mini`），或在控制台搜不到时走第 5 节的「推理接入点」路线。

### 四、开通「联网内容插件」（联网查真实车票/酒店必需）

1. 同一页「开通管理」切到 **「插件」** 分类。
2. 找到 **「联网内容插件（Web Search）」**，点 **「开通」**（免费）。
3. 不开通的话，App 里「联网查真实车次/航班」会失败，只能退回普通模式（车票给建议、酒店待定）。

官方说明：[Web Search（联网内容插件）- 火山方舟](https://ark.volcengine.com/region:cn-beijing/docs/82379/1756990?lang=zh)

### 五、（推荐可选）创建「推理接入点」ep-xxx

用**模型 ID 直连**在第 3 步开通后即可工作；若仍报「模型不存在」或想固定一个模型，可创建推理接入点：

1. 左侧菜单 → **「在线推理」→「创建推理接入点」**。
2. 模型选择 **豆包 Seed 2.0 Lite**（或你已开通的模型），按需设置后创建。
3. 创建完成会得到一个 **`ep-xxxxxxxx`** 形式的接入点 ID——把它填进 App 的「模型名称 / 推理接入点」框即可（用 ep 不会再报 ModelNotOpen）。

### 六、填进 App 并测试

1. App「更多 → AI 生成设置」：
   - 服务商：**豆包(火山方舟)**；
   - 接口地址：保持默认 `https://ark.cn-beijing.volces.com/api/v3`；
   - **模型名称 / 推理接入点**：填模型 ID `doubao-seed-2-0-lite-260428`，或你创建的 `ep-xxx`；
   - API Key：填第 2 节复制的 Key；
   - 打开 **「联网查真实车次/航班」** → 保存。
2. 到「AI 规划」页生成一次行程。成功后聊天区会出现「已联网核实到真实车票/酒店」，生成完可在「车票」页与 12306 核对。

### 七、常见报错对照表

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `ModelNotOpen` / 「账号未开通模型」 | 模型服务没开通（第 3 节） | 控制台「开通管理 → 模型服务」开通该模型，或改用推理接入点 ep-xxx |
| 「模型不存在 / model not found」(404) | 模型 ID 填错或该版本已下线（如 1.6 系列） | 填控制台显示的准确模型 ID，或直接填 ep-xxx |
| 「联网核实未成功…已改用普通模式」 | ①「联网内容插件」未开通；②联网较慢超时 | 开通插件后重试；联网首步需 1～3 分钟，请耐心等它跑完 |
| `MissingParameter: tools.function.parameter` | 用 chat/completions 传 web_search 工具（旧版问题，本 App 已改走 Responses API，新版不会再遇到） | 更新到 v2.0 版本 |
| 一直转圈 / 超时 | 网络慢或服务繁忙 | 稍后重试；App 已自动放宽超时并重试一次 |

### 八、费用提示

方舟按调用量**后付费**，模型价格以控制台「开通管理 / 价格页」为准；常见模型有免费额度活动（以控制台活动为准）。个人规划旅行用量很小，费用通常可忽略。

## 隐私

- 所有行程数据**只存本机**（Room 数据库），不上传任何服务器；
- 只有在你点「AI 规划」时，把行程需求发给火山方舟官方 API 用于生成，不存你的旅行数据；
- API Key 只保存在本机 SharedPreferences。
